## Turn 3 — `.git` vs `.github`, `.gitattributes`

### User

```
.git 폴더가 있잖아. 근데 .github폴더를 추가한 이유가 뭐야? 없앨수있으면 없애고,
.gitattributes이건 뭐야?
```

### Assistant

| | `.git` | `.github` |
|---|--------|-----------|
| 역할 | Git **저장소** (커밋·히스토리) | GitHub **Actions CI** 설정 |
| 필수 | Git 사용 시 필수 | GitHub CI 안 쓰면 **불필요** |

- **`.github`**: Turn 1 요구사항(CI)으로 `ci.yml` 추가했으나, 로컬 전용이면 제거 가능 → **사용자 요청으로 `.github/` 삭제**.
- **`.gitattributes`**: Git이 파일별 줄바꿈·텍스트 처리 규칙. 현재 `test/golden/*.golden text eol=lf` — Windows CRLF로 golden diff 지저분해지는 것 방지. 빌드·테스트 무관, golden Git 관리 시 **유지 권장**.
