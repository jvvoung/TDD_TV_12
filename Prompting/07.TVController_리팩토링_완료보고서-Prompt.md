## Turn 2 — Phase 1~3 구현

### User

```
Phase 1 → 2 → 3 (위험 대비 효과 최대) ->진행해줘.
```

### Assistant

**변경 파일**: `include/TVController.h`, `docs/refactoring_log.md` (신규)

#### Phase 1 — 상수화

| 상수 | 용도 |
|------|------|
| `MAX_DIGIT_BUFFER = 2` | 2자리 입력 상한 |
| `SINGLE_DIGIT_LENGTH = 1` | 1자리·OK 분기 |
| `SEEK_LOOP_GUARD = MAX_CHANNEL + 1` | `seekCH` 루프 가드 |
| `CHANNEL_ZERO = "0"` | 선행 0 (`1-5`) |

#### Phase 2 — 중복 제거

- **`setTunerCh`**: `parseChannelValue` 1회; `normalizeChannelString`·`isValidChannelString` **제거**
- **`adjustChannelStep(delta)`** + **`tuneToChannelValue`**: `channelUp`/`channelDown` 통합, `searchResults.empty()` 단일 분기 유지
- **`clearDigitBuffer()`** / **`discardDigitBufferIfNonEmpty()`**: 선호·검색 vs CH_UP/DOWN(`1-4b` early return) 의도 분리

#### Phase 3 — `handleDigit` 분해

- `startDigitEntry`, `appendSecondDigitAndConfirm`, `replaceLeadingZeroAndConfirm`, `restartDigitEntry`
- `hasSingleDigitInBuffer`, `hasLeadingZeroInBuffer`
- `handleConfirm` → `hasSingleDigitInBuffer()` 재사용

**미변경**: `Tuner.h`, `remoteKey.h`, `test/TunerTest.cpp`, `TVControllerTest.cpp`, `GoldenMasterTest.cpp`, `test/golden/*.golden`

**검증**

```
cmake --build build
ctest --test-dir build --output-on-failure
→ 100% tests passed, 0 failed out of 78
   (TunerTest 13 + TVControllerTest 39 + GoldenMasterTest 26)
```

**고위험 Green 확인**: `TC_1_4b`, `TC_1_4a`, `TC_1_5`, `TC_6_3`/`6_4`, `TC_A8`, `TC_ERR_InvalidCurrentChUpNoOp`, Golden `Scenario_1_4b_*`

**부수 이슈**: `TVController.h` 일시 이중 줄바꿈 포맷 → 정상 CRLF로 재작성 후 재검증 Green.
