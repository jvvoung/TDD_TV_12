## 1. 보고 목적

`README.md`는 6개 기능 시나리오를 **자연어 예시**로 제시하지만, C++17·Google Test/Mock 기반 TDD를 진행하려면 다음이 선행되어야 한다.

- 키 입력마다 **Tuner API 호출 시점**(`setCH` / `getCurrentCH` / `seekCH`) 명확화
- **내부 상태**(숫자 버퍼, 선호 목록, 검색 결과) 전이 규칙
- README **모호·누락** 항목에 대한 구현 가정 및 acceptance 테스트 기준

본 보고서는 위 분석 활동의 **요약·의사결정 기록**이며, 구현·테스트 작성 시 상세 규칙은 `docs/requirements_analysis.md`를 단일 기준(Single Source of Truth)으로 사용한다.

## 4. 기능 요약 (비즈니스 규칙)

### 4.1 README 시나리오 대응표

| README # | 기능 | 핵심 규칙 (권장 가정) | 주 Tuner 호출 |
|----------|------|----------------------|---------------|
| 1 | 숫자 + 확인 | 1자리→`KEY_OK` 확정; 2자리→두 번째 숫자 즉시 `setCH`; 선행 `0` 대체 | `setCH` |
| 2 | 선호 채널 토글 | 시청 중 추가/삭제, 채널 변경 없음 | `getCurrentCH` |
| 3 | 다음 선호 | 현재보다 큰 최소값, 없으면 최소값 로테이션 | `getCurrentCH` → `setCH` |
| 4 | 채널 검색 | `seekCH()`를 `""` 반환 전까지 반복, 결과 저장·정렬·중복 제거 | `seekCH` × N |
| 5 | 업/다운 (검색 없음) | ±1, 99↔0 래핑 | `getCurrentCH` → `setCH` |
| 6 | 업/다운 (검색 있음) | 저장 목록 내 next/prev, 목록 외 채널도 래핑 규칙 적용 | `getCurrentCH` → `setCH` |

### 4.2 업/다운 분기 (단일 조건)

```
searchResults.empty() ?
  YES → ±1 래핑 (README §5)
  NO  → 검색 목록 탐색 (README §6)
```

선호 채널 목록은 업/다운 분기에 **관여하지 않음**.

### 4.3 숫자 입력 상태 머신 (요약)

```
[빈 버퍼]
   │ 숫자
   ▼
[1자리] ── KEY_OK ──► setCH ──► [빈]
   │ 숫자(2자리)
   ▼
[2자리] ── 자동 ──► setCH ──► [빈]
   │
   └── 선행 "0" + 숫자 → "0" 대체 후 확정 (예: 0,7 → 7)

[1자리 미확정] + (숫자·OK 외 키) → 버퍼 무효화 (예: 4,5,6 후 UP)
```

## 6. 설계 권고사항

### 6.1 `remoteKey` 확장

현재 `KEY_1`, `KEY_OK`만 존재. README 키 전체에 대응하는 enum 추가 권장:

- `KEY_0` … `KEY_9`
- `KEY_CH_UP`, `KEY_CH_DOWN`, `KEY_OK`
- `KEY_CHANNEL_SEARCH`, `KEY_FAVORITE_TOGGLE`, `KEY_NEXT_FAVORITE`

`to_string(remoteKey)`는 디버그·로그용으로 enum과 **동기 유지**.

### 6.2 `TVController` 내부 상태

| 멤버 | 타입(권장) | 역할 |
|------|------------|------|
| `processingCH` | `std::string` | 숫자 입력 버퍼 (기존) |
| `favoriteChannels` | `std::set<int>` | 선호 채널 (오름차순) |
| `searchResults` | `std::vector<int>` | 마지막 검색 결과 (정렬·유일) |

### 6.3 문자열·숫자 처리

- Tuner API는 `"0"`~`"99"` 문자열; 내부 비교·±1·목록 탐색은 **`stoi` 후 정수** 권장
- `setCH` 인자는 선행 0 없음 (`"7"`, not `"07"`)
- 무효 채널(`-1`, `100` 등)은 Controller가 **호출 전 차단** (`TunerTest` invalid 시나리오와 정합)
