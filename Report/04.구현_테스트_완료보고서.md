선호/검색/다음선호는 버퍼 클리어 **후** 본래 동작을 수행한다 (`1-4b` vs `A6`).

## 4. 구현 요약

### 4.1 `remoteKey.h`

- enum 16개 키 + `to_string()` switch 전 case 처리
- 스켈레톤(`KEY_1`, `KEY_OK`만 존재)에서 README 키 목록 전체 반영

### 4.2 `TVController.h` 내부 상태

| 멤버 | 타입 | 역할 |
|------|------|------|
| `processingCH` | `std::string` | 숫자 입력 버퍼 |
| `favoriteChannels` | `std::set<int>` | 선호 채널 (오름차순) |
| `searchResults` | `std::vector<int>` | 마지막 검색 결과 (정렬·중복 제거) |

### 4.3 주요 처리 흐름

```
pushButton(key)
  ├─ KEY_0..9     → handleDigit (2자리 즉시 확정, 0+숫자 정규화)
  ├─ KEY_OK       → handleConfirm (1자리만)
  ├─ KEY_FAVORITE → clearBuffer + toggleFavorite (setCH 없음)
  ├─ KEY_NEXT_FAV → clearBuffer + nextFavorite (upper_bound / 로테이션)
  ├─ KEY_CH_SEARCH→ clearBuffer + runChannelSearch (seekCH until "")
  ├─ KEY_CH_UP    → pending buffer 시 clear만 / else channelUp
  └─ KEY_CH_DOWN  → pending buffer 시 clear만 / else channelDown

channelUp/Down
  ├─ searchResults 비어 있음 → getCurrentCH ±1, 0↔99 래핑
  └─ searchResults 있음     → 목록 내 이웃 / 목록 외 래핑 (6-3, 6-4)
```

- `setTunerCh`: `0~99` 선검증 후 `tuner->setCH` (무효 시 미호출)
- `getCurrentCH` 파싱 실패 시 업/다운·선호 no-op (`E14`)
